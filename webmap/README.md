# Коалесцентная карта мира — интерактив

## Запуск (нужен локальный сервер — id-буфер читается из пикселей)
```
cd webmap
python3 -m http.server 8000
```
Открыть http://localhost:8000/

## Возможности
- Слои: «Симуляция», «Реальная карта», «Разница территорий» (расходящаяся раскраска: красный — потерял, зелёный — приобрёл).
- Переключение внешних и внутренних границ.
- Клик по области → страна, реальная/модельная площадь, разница, индекс расхождения; подсветка всех её областей; огибающая (для несекущих море — готовая, для остальных строится в браузере).
- Рейтинги: разница площадей, расхождение границ, навязанность границ (отклонение реальной границы от модели / людской масштаб; клик подсвечивает обе страны пары).
- Анимация роста от семян до готовой карты (воспроизведение по рангу — плавно), ползунок, скорость, живой счётчик захваченной площади выбранной страны.
- «Как получается карта» — описание модели.

## Режим «с поглощением анклавов»
Переключатель «Режим» вверху сайдбара. Альтернативная симуляция: кусок страны, полностью окружённый одной другой страной и без выхода к открытому океану, переходит к ней (с пересчётом населения/скорости). Защищены истинные сухопутные анклавы (Лесото, Сан-Марино). Подменяются ассеты *2 (map_sim2, ids_sim2, arrival_sim2, borders2, countries2, rankings2, map_diff2); реальный слой и берег общие.
